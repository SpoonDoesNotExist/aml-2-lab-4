## Цель и конфигурация

Я описал инфраструктуру Yandex Cloud на HCL: VPC, подсеть 10.10.0.0/24 в ru-central1-a и две ВМ Ubuntu 22.04 LTS с 2 vCPU и 2 ГБ RAM. На web через cloud-init установил Docker и запустил nginx на порту 8080. На worker запустил Python-службу, которая раз в минуту пишет в /var/log/worker.log.

Для web разрешил входящие TCP/22 и TCP/8080 из интернета, для worker - только TCP/22 из подсети. У worker nat = false. Параметры вынес в variables.tf, адреса - в outputs.tf. Провайдер yandex-cloud/yandex 0.244.0; авторизация через окружение из yc, state локальный.

## Планирование и создание

```text
$ terraform plan
Plan: 6 to add, 0 to change, 0 to destroy.

$ terraform apply .local/create.tfplan
Apply complete! Resources: 4 added, 0 changed, 0 destroyed.
```

В успешном apply добавились 4 ресурса: две ВМ и две группы безопасности. Сеть и подсеть уже были созданы предыдущим запуском. Всего в инфраструктуре 6 ресурсов. Полученные адреса: web - 51.250.10.147 и 10.10.0.18; worker - 10.10.0.25.
